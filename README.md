# 💖 Nosso Date Interativo

Um aplicativo web romântico e interativo desenvolvido em HTML, CSS e JavaScript, criado especialmente para convidar a namorada para um date de forma criativa, divertida e personalizada.

## ✨ Funcionalidades Principais

* **Fundo Animado Dinâmico:** Ecrã decorado com fotografias flutuantes e corações a moverem-se suavemente de forma aleatória.
* **Caixa Central Estilizada (Glassmorphism):** Um cartão central moderno com efeito de vidro fosco (`backdrop-filter`) e uma **foto de fundo personalizada (`fundo.png`)** com transparência suave para garantir legibilidade.
* **Botão "NÃO" Inteligente:** Um botão interativo que se recusa a ser premido — ele foge de forma inteligente na direção oposta ao cursor do rato ou toque, com limites restritos para garantir a diversão!
* **Escolha de Comida e Vibe (Até 2 opções):** 
  * Grelhas interativas com limite máximo de 2 seleções por categoria (com avisos visuais do tipo *toast*).
  * Campo de texto personalizado ("Outra coisa / Outra vibe") integrado dinamicamente nas escolhas.
* **Agendamento de Data e Hora:** Selecionador de data e horário flexível para definir o momento perfeito do encontro.
* **Integração Completa com o WhatsApp:** Resumo final organizado e codificado de forma segura que envia automaticamente a mensagem de confirmação para o número configurado (`5511959355941`) com a frase especial: *"Fica pronta que eu vou te buscar 🏍️💨"*.

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação e organização de ecrãs/fluxos)
* **CSS3** (Estilização moderna, variáveis, animações `@keyframes` e efeitos de blur)
* **JavaScript Vanilla** (Lógica de navegação entre ecrãs, sistema de fuga do botão, gestão de limites e montagem do link do WhatsApp)

## 🚀 Como Executar Localmente

1. Clona este repositório ou descarrega os ficheiros.
2. Certifica-te de que as imagens (`image.png`, `image_2.png`, ..., `fundo.png`) estão na mesma pasta do ficheiro `index.html`.
3. Abre o ficheiro `index.html` em qualquer navegador web moderno.
